# da-yoshi-k.github.io

![OGP preview](public/ogp.png)

よしだの自己紹介ページ（リンク集/プロフィール）です。

## 公開ページ

- URL: https://da-yoshi-k.github.io/

## 技術スタック

- Astro
- TypeScript
- Tailwind CSS

## ローカル起動

```bash
npm install
npm run dev
```

## 反映方法

- `src/content/links/*.md` を追加・編集するとリンクカードが更新されます。
- `src/components/` でカードやプロフィール表示を調整できます。
